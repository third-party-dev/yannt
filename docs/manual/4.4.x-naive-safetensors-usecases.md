# Naive SafeTensors Use Cases

## Safetensors Test Data Generation

Assumptions:

- The current working directory is the project folder (`.yannt` or `/work`)

Create an untrained Bert model as a Safetensors (outside container):

```sh
mkdir -p ./models/bert
hft create --type AutoModel --model bert \
  --safetensors_path ./models/bert/safetensors
```

## Use Case: Load PyTorch with torch

Example Command:

```sh
yannt naive --breakpoint safetensors parse ./models/bert/safetensors/model.safetensors
```
