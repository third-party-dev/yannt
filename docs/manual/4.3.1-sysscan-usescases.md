# System Scan Use Cases

## Use Case Synopsis

- Quick Scan (grab things with points, no needle/haystack searching)
  - Run quick scan from CLI
- Full Scan (quick scan + needle/haystack searching)
  - Run full scan from CLI

## Use Case: Quick Scan (grab things with points, no needle/haystack searching)

Run quick scan from CLI:

```sh
yannt sysscan quick
```

Example Run:
