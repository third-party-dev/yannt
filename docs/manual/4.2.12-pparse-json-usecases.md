# Pparse Json Use Cases

Generate test data.

```sh
yannt pparse safetensors header models/bert/safetensors/model.safetensors > models/bert/safetensors/model-header.json
```

```sh
yannt pparse --breakpoint json view models/bert/safetensors/model-header.json
```

```sh
yannt pparse json view --print models/bert/safetensors/model-header.json
```
