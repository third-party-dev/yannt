
Extract safetensors header from python:

```python
import json
import struct

filepath = './models/bert/safetensors/model.safetensors'
with open(filepath, "rb") as fobj:
    header_length = struct.unpack("<Q", fobj.read(8))[0]
    hdr_json = json.dumps(json.loads(fobj.read(header_length).decode()), indent=4)
    print(hdr_json)
```

## Extract and parse into a node tree (for non-humans) safetensors JSON header

Parse and inspect from CLI:

```sh
yannt pparse --breakpoint safetensors pheader ./models/bert/safetensors/model.safetensors
```

Parse in python:

```python
from thirdparty.pparse.view.safetensors import SafeTensors

node_tree = SafeTensors().open_fpath(args.path)
```
