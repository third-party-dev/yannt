# Flatbuffers Use Cases

## Flatbuffers Test Data Generation

Assumptions:

- The current working directory is the project folder (`yannt` or `/work`)
- You have access to huggingface.co

Download model:

```sh
mkdir -p ./models/yolov5su
wget -O ./models/yolov5su/yolov5su.mnn https://huggingface.co/third-party-dev/yolo5su/resolve/main/yolov5su.mnn
```

## Use Case: Parse Flatbuffers

```sh
yannt pparse --breakpoint flatbuffers view ./schemas/MNN.json ./models/yolov5su/yolov5su.mnn
```

```sh
yannt pparse flatbuffers view --print ./schemas/MNN.json ./models/yolov5su/yolov5su.mnn
```
