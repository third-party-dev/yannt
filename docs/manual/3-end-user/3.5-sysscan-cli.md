## sysscan CLI

The `sysscan` subcommand is design to look for AI artifacts on the system its run on. It will look for dotfiles, kernel modules, and specific device files known to be associated with ML related systems. For example, it can find if your system is equipped with NVIDIA kernel module and device driver or whether you have PyTorch installed into your system or home folders.

The subcommand has a full scan that takes longer because it scans the entire filesystem. The quick check does all the checks that are more direct and have significantly less scanning by nature.

```sh
# yannt sysscan --help
usage: yannt sysscan [-h] [--breakpoint] {full,quick} ...

positional arguments:
  {full,quick}
    full        full sysscan command
    quick       quick sysscan command

optional arguments:
  -h, --help    show this help message and exit
  --breakpoint
```

The output for the quick scan is a simple report on what was found. Example:
