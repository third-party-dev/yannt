# End User Documentation

The End User Documentation is primarily focused on CLI usage of the tool. While the full potential of yannt/pparse can be utilized programmatically in code, there is a large amount of use cases that can be used from CLI. This includes the parsing of binary files to printable and human readable data structures encode in JSON and/or XML. There are different features included with each file format, for example:

- safetensors header extraction
- pytorch pickle extraction
- generic flatbuffers parser, given a schema file path
- and so forth

In general, you can see all of the features that yannt tools have by utilizing the `--help` argument on the CLI.

**Note:** For installation, please see the installation procedures in section 1.
