### 4.5.x Naive PyTorch Use Cases

<div class="h3-style">PyTorch Test Data Generation</div>

Assumptions:

- The current working directory is the project folder (`.yannt` or `/work`)

Create an untrained Bert model as a PyTorch complete and weights-only models:

```sh
mkdir -p ./models/bert
hft create --type AutoModel --model bert --pytorch_params_path ./models/bert/pt
```

<div class="h3-style">Use Case: Load PyTorch with torch</div>

Example Command:

```sh
yannt naive --breakpoint pytorch load ./models/bert/pt/bert-AutoModel.params.pt
```
