# PyTorch Use Cases

## Use Case Synopsis

- Generate Arc Hash of (Weights Only) PyTorch File
  - Generate arc hash from CLI
  - Inspect arc generation results at runtime with CLI
- Parse (Weights Only) PyTorch File For Tensor Extraction
  - Parse pt file from CLI and inspect from pdb
  - Parse pt file from Python and inspect
- Parse data.pkl pre-extracted from (any) PyTorch file (no unpickle() used!)
  - Parse the `data.pkl` from command line
- Transform (Weights Only) PyTorch into Safetensors
  - Transform pytorch to safetensors from CLI
  - Transform pytorch to safetensors from python

## PyTorch Test Data Generation

Assumptions:

- The current working directory is the project folder (`.yannt` or `/work`)

Create an untrained Bert model as a PyTorch complete and weights-only models:

```sh
mkdir -p ./models/bert
hft create --type AutoModel --model bert --pytorch_params_path ./models/bert/pt
hft create --type AutoModel --model bert --pytorch_path ./models/bert/pt
# Extract the data.pkl (and data) from the PyTorch zip file.
cd ./models/bert/pt ; unzip bert-AutoModel.complete.pt ; cd ../../..
```

## Use Case: Generate Arc Hash of (Weights Only) PyTorch File

Generate arc hash from CLI:

```sh
yannt pparse pytorch hash ./models/bert/pt/bert-AutoModel.params.pt
```


Parse the pkl from python (using low level lazy paring API):

```python
import thirdparty.pparse.lib as pparse
from thirdparty.pparse.lazy.pickle import Parser as LazyPickleParser

try:
    #'output/gpt2-pytorch/data.pkl'
    parser_reg = {"pkl": LazyPickleParser}
    data_source = pparse.FileData(path=args.path)
    data_range = pparse.Range(data_source.open(), data_source.length)
    root = pparse.BytesExtraction(name=args.path, reader=data_range)
    root.discover_parsers(parser_reg).scan_data()

except pparse.EndOfDataException as e:
    print(e)
    pass
    
top_of_node_tree = root._result["pkl"]
top_of_pkl_data = root._result["pkl"].value[0].value[0]
```

Transform pytorch to safetensors from python:

```python
from thirdparty.pparse.view.pytorch import PyTorch
obj = PyTorch().open_fpath('./models/bert/pt/bert-AutoModel.params.pt')
obj.as_safetensors('./outputs/test.safetensors', keep_lm_head=False)
```
