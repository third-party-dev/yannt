## 1.2 Installing Yannt (and Pparse) CLI

### 1.2.1 Determine The Python Environment

Yannt/pparse have been designed to work with many different environments, including venv, uv, conda, docker, podman, windows, linux, and so forth. Please consider not installing yannt/pparse in your system python environment (unless virtualized or containerized). At a minimum, isolating the install into a virtual python environment will ease upgrading in the future.

A common python way to create a new virtual environment is to use venv:

```sh
mkdir -p ~/thirdparty
cd ~/thirdparty
python -m venv venv
```

Then if you want to enter your python environment, use something like:

```sh
bash --rcfile <(echo "source ~/thirdparty/venv/bin/activate")
```

This has the advantage of using a clean bash environment and then you can `exit` when you want to leave the environment (in contrast to a complicated and fragile _deactivate_ process).

### 1.2.2 Install The Packages Based On Needs

Yannt and pparse are primarily distributed as python wheels. At the time of writing this documentation, yannt and pparse are not upstreamed into any upstream repositories. Therefore you must provide extra flags to pip to point at the folder that contains the appropriate wheels.

For example, if the wheels are in `/home/user/wheels`, you can use something similar to:

```sh
pip install -f /home/user/wheels <packages>
```

Note: The commands below assume that you've either configured your pip.conf or you are using the `-f` flag as appropriate.

Installing a minimal useful setup of yannt can be as simple as:

```sh
pip install thirdparty-yannt thirdparty-pparse thirdparty-yannt-analyze
```

If you want to generate toy models to analyze with yannt, you can use `thirdparty-hft`:

```sh
pip install thirdparty-hft
```

`thirdparty-hft` is a wrapper around the Huggingface Transformers library used by Huggingface to initialize its models. Yannt uses it to construct untrained (zero-ed or randomized) models. Using `hft` makes it easy to generate a number of models locally without having to download and import real models into your analysis environment. Installing `hft` will also require installing pytorch and associated dependencies.

Yannt includes several "naive" packages. Naive packages are packages that depend on the upstream libraries to perform parsing that pparse and yannt are attempting to mock. They are useful for running the test suites and for comparing the pparse way to the "normal" (non-forensic) way. Installing "naive" packages usually involves installing upstream libraries that may or may not actually work on their own. They often need to be run in a specialized container environments, so your milage may vary.

### 1.2.3 Testing The Install

Once the packages you want are installed, go ahead and test with:

```sh
yannt --help
```

If you don't have the python entry point path setup in your `PATH`, you may need to explicitly run something like:

```sh
~/.local/bin/yannt --help
```
