### ONNX Use Cases

<div class="h3-style">Onnx Test Data Generation</div>

Assumptions:

- The current working directory is the project folder (`yannt` or `/work`)
- You have access to huggingface.co

Download model:

```sh
mkdir -p ./models/yolov5su
wget -O ./models/yolov5su/yolov5su.onnx https://huggingface.co/third-party-dev/yolo5su/resolve/main/yolov5su.onnx
```

<div class="h3-style">Use Case: Parse ONNX</div>

```sh
yannt pparse --breakpoint onnx view ./models/yolov5su/yolov5su.onnx
```

```sh
yannt pparse onnx view --print ./models/yolov5su/yolov5su.onnx
```
