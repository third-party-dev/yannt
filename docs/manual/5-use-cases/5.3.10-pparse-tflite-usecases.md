### TFLite Use Cases

<div class="h3-style">TFLite Test Data Generation</div>

Assumptions:

- The current working directory is the project folder (`yannt` or `/work`)
- You have access to huggingface.co

Download model:

```sh
mkdir -p ./models/yolov5su
wget -O ./models/yolov5su/yolov5su_float32.tflite https://huggingface.co/third-party-dev/yolo5su/resolve/main/yolov5su_saved_model/yolov5su_float32.tflite
```

<div class="h3-style">Use Case: Parse TFLite</div>

```sh
yannt pparse --breakpoint tflite view ./models/yolov5su/yolov5su_float32.tflite
```

```sh
yannt pparse tflite view --print ./models/yolov5su/yolov5su_float32.tflite
```
