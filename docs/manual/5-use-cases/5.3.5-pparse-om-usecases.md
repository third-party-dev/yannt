:::warning
BROKEN
:::

<div class="h3-style">Use Case Synopsis</div>

- Parse OM header only
- Parse OM header and modeldef protobuf stream

<div class="h3-style">Om Test Data Generation</div>

Assumptions:

- The current working directory is the project folder (`yannt` or `/work`)
- You have access to huggingface.co

Download model:

```sh
mkdir -p ./models/yolov5su
wget -O ./models/yolov5su/yolov5su.om https://huggingface.co/third-party-dev/yolo5su/resolve/main/yolov5-om/yolov5su.om
```

<div class="h3-style">Use Case: Parse OM header and modeldef</div>

:::warning
WARNING: Code currently assumes the 2nd partition is the ModelDef. To be fixed!
:::

The ModelDef data structure is very large. It is only recommended to inspect at runtime.

```sh
yannt pparse --breakpoint om parse yolov5su.om
```

Do it in python:

```python
from thirdparty.pparse.view.om import Om

obj = Om().open_fpath("yolov5su.om")
header = obj._extraction._result['om']
modeldef = obj._extraction._extractions[0]._result['protobuf']
```
