# OM Use Cases

## Use Case Synopsis

- Parse OM header only
- Parse OM header and modeldef protobuf stream

```sh
yannt pparse --breakpoint om header yolov5su.om
```

## Use Case: Parse OM header and modeldef

WARNING: Code currently assumes the 2nd partition is the ModelDef. To be fixed!

The ModelDef data structure is very large. It is only recommended to inspect at runtime.

```sh
yannt pparse --breakpoint om parse yolov5su.om
```

Do it in python:

```python
from thirdparty.pparse.view.om import Om

obj = Om().open_fpath("yolov5su.om")
header = obj._extraction._result['om']
modeldef = obj._extraction._extractions[0]._result['protobuf']
```
