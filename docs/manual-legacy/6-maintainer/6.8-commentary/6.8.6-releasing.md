### 6.8.6 Releasing

Yannt release process is *special* to say the least. Ideally we'd build environments for all of the python versions we want to support and then build and push those packages with twine. Users would then simply `pip install` the package.While this flow remains feasible for upstream pypi, circumstances have prevented this flow from being possible in all applicable scenarios.

Pypi (i.e. twine/pip) access is still being developed.
An alternative Generic package access is also still being developed.

<div class="h3-style">Offline Install</div>

As part of the build process, (assuming upstream/mirror pypi access) yannt and pparse generate a folder in the `outputs/dist` that includes the minimal packages required without including `hft`/`naive` plugins. In other words, it is 2 folders of python packages required to install yannt and pparse without any of the heavy frameworks like torch, tensorflow, or ultralytics. None of the yannt packages or pparse have any interdependencies so they can be installed completely independent of each other.

However one gets the packages to their offline network given the package path is `$PIP_PKGS`, you simply run:

```sh
pip install -f $PIP_PKGS -r $PIP_PKGS/requirements.txt
```

Assuming that was successful, the relevant package and its dependencies will be installed.

<div class="h4-style">Full Example Flow</div>

From inside podman/docker environment:

```sh
./do builddevpkgs 0.0.4
./do builddevpparse 0.0.4
```

From top level yannt folder:

```sh
# Compile It
YANNT_VERSION=yannt-pkgs-py3.9.25-0.0.4.dev17+g4a02aa3
PPARSE_VERSION=pparse-pkgs-py3.9.25-0.0.4.dev35+g04ad1d7

DIST_PATH=${YANNT_VERSION}_${PPARSE_VERSION}
mkdir -p outputs/$DIST_PATH
cp outputs/dist/$YANNT_VERSION/* ./outputs/$DIST_PATH/
cp packages/thirdparty_pparse/outputs/dist/$PPARSE_VERSION/* ./outputs/$DIST_PATH/
cat outputs/dist/$YANNT_VERSION/requirements.txt \
  packages/thirdparty_pparse/outputs/dist/$PPARSE_VERSION/requirements.txt \
  > outputs/$DIST_PATH/requirements.txt

# Test It
cd outputs/$DIST_PATH
python3 -m venv yannt-venv
. ./yannt-venv/bin/activate
pip install -f . -r requirements.txt
yannt --help
pparse --help
deactivate

# Bundle It
rm -rf yannt-venv
cd ..
tar -czf $DIST_PATH.tar.gz $DIST_PATH
cd ..
```

Optionally publish to generic package repo:

```sh
CERT_ARGS="-k --cert PATH_TO_CLIENT_CERT_HERE"
GL_TOKEN=TOKEN
ENDPT=https://gitlab_host/api/v4/projects/group%2Fproject/packages

curl $CERT_ARGS \
  --header "PRIVATE-TOKEN: $GL_TOKEN" \
  --upload-file outputs/$DIST_PATH.tar.gz \
  "$ENDPT/generic/min_yannt_pparse/$DIST_PATH/$DIST_PATH.tar.gz"
```
